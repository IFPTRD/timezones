# Deployment

- Repository: https://github.com/IFPTRD/timezones
- GitHub Pages: https://ifptrd.github.io/timezones/
- Source: `main`, repository root.

The October 22, 2026 revamp replaces the original clock list with grouped time relationships, an inline calendar and slider, bilingual controls, and explicit verified 2026/2027 rules.

Run `node time.test.js` before deploying. Browser regression checks are in `browser.test.cjs`; Playwright Chromium and OS libraries are required. Verify the Pages deployment after pushing. See SOURCES.md for the accuracy scope; older deployment notes and blanket claims about provincial DST policies are superseded.
